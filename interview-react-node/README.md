# Full-Stack Invoices App

This project is a **full-stack application** for managing invoices, consisting of a **NestJS backend** and a **React frontend**, both containerized with **Docker**.

## 📌 Features
- **JWT authentication**
- **Invoice management** (list, filter, and view details)
- **Pagination & search**
- **Scalable backend** with NestJS and Prisma
- **PostgreSQL database**
- **Automated testing with Playwright**
